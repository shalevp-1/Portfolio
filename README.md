# Portfolio Website

My personal portfolio website, built to showcase my projects, technical skills, and experience as a web developer.

**Live Website:** [shalevpeck.netlify.app](https://shalevpeck.netlify.app/)

## Built With

- React
- TypeScript
- CSS
- Netlify

## Features

- Responsive portfolio layout
- English and Hebrew language support
- Right-to-left layout for Hebrew
- Project showcase with image carousels
- Technical skills section
- Contact links
- Scroll-based animations

## Projects

The portfolio showcases my web development projects, including:

- **[FiTrack](https://fitrackfitness.netlify.app/home)** — A fitness tracking application built with Angular, Node.js, Express, and MySQL.
- **[Donuts](https://dountstime.netlify.app/)** — A full-stack web application built with React, Node.js, and MySQL.

## Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/shalevp-1/Portfolio.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Portfolio
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm start
   ```
